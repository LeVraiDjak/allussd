All USSD

English

Tous les codes USSD de votre opérateur, dans votre poche. Fonctionne hors-ligne, sans compte.

Consulter son solde, acheter un forfait, connaître son numéro, envoyer de l'argent : chaque opérateur a ses codes, et personne ne les retient tous. All USSD les rassemble par pays et par opérateur, les rend cherchables, et les compose en un tap — l'application ouvre le composeur du téléphone avec le code déjà saisi, vous appuyez vous-même sur Appeler.

  • 22 langues d'interface
  • 100 % hors-ligne
  • 0 permission demandée
  • 0 compte à créer

Ce qui la distingue

  • Hors-ligne intégral — aucune connexion nécessaire, y compris quand il ne reste plus ni crédit ni data (exactement le moment où l'on cherche un code).
  • Aucun accès à vos données — l'application ne demande ni vos contacts, ni votre position, ni le droit de passer des appels à votre place. Votre pays et votre opérateur sont simplement lus sur la carte SIM, sans GPS.
  • Codes dangereux verrouillés — parmi les codes fournis avec l'application, ceux qui peuvent effacer votre téléphone restent visibles mais ne se composent pas, avec l'explication de ce qu'ils font.
  • Double SIM — deux opérateurs sélectionnables en même temps.
  • Numéros d'urgence locaux — police, gendarmerie, pompiers, SAMU, pour chaque pays couvert.

Aider : signaler un code ou un numéro d'urgence

Les codes opérateur changent, et aucune source en ligne n'est fiable partout. Chaque code de l'application est soit confirmé sur un vrai téléphone, soit marqué « non vérifié » en attendant de l'être. C'est là que vous pouvez aider — deux minutes suffisent :

Un code ne marche pas Proposer un code manquant Un numéro d'urgence est faux ou manquant

Un signalement ouvert sur GitHub est public : n'y mettez pas votre numéro de téléphone ni quoi que ce soit de personnel — le pays, l'opérateur (ou le service) et le code (ou le numéro) suffisent.

Aucun compte GitHub ? Écrivez simplement à levraidev@gmail.com, en précisant le pays, l'opérateur ou le service, le code ou le numéro, et ce que vous avez constaté.
