Politique de confidentialité — All USSD

English

Dernière mise à jour : 22 août 2026

All USSD est une application mobile qui rassemble les codes USSD/MMI et les codes opérateurs par pays, avec composition en un tap. Cette page décrit comment vos données sont traitées.

En résumé : All USSD ne collecte aucune donnée personnelle. L'application fonctionne entièrement hors-ligne et sans compte.

Ce que l'application ne fait pas

  • Aucun compte utilisateur, aucune inscription
  • Aucune connexion internet requise pour fonctionner
  • Aucun accès aux contacts, à la localisation ou à toute autre donnée personnelle
  • L'application ne vous demande aucune autorisation, et n'en détient aucune : composer un code ouvre l'application Téléphone du système avec le numéro prérempli, et c'est vous qui appuyez sur Appeler

Données stockées sur votre appareil

Vos réglages et vos choix dans l'application (favoris, préférences, codes que vous ajoutez vous-même) restent sur votre téléphone.

Signalement volontaire d'un code

Si vous utilisez le bouton « Signaler ce code » ou « Proposer un nouveau code », vous choisissez vous-même comment l'envoyer : par e-mail, ou en ouvrant un formulaire sur GitHub. Ne partent que les informations affichées à l'écran : pays, opérateur, nom et code concernés, et ce que vous décrivez du problème. Cet envoi est volontaire et déclenché par vous à chaque fois ; l'application ne transmet jamais rien automatiquement.

Un signalement ouvert sur GitHub est public et le reste. Les deux autres choix ne le sont pas.

Partage avec des tiers

Nous ne partageons aucune donnée avec des tiers, puisque nous n'en collectons aucune.

Vos droits

Toutes les données de l'application vivent sur votre appareil : vous pouvez les consulter directement dans l'application et les supprimer depuis ses réglages.

Modifications de cette politique

Cette politique évolue avec l'application. La date en haut de page indique la version en vigueur.
