Every USSD code your carrier has, in your pocket. Works offline, no account.

Checking your balance, buying a bundle, finding your own number, sending money: every carrier has its own codes, and nobody remembers them all. All USSD gathers them by country and by carrier, makes them searchable, and dials them in one tap — the app opens your phone's dialler with the code already typed in, and you press Call yourself.

  • 21 interface languages
  • 100% offline
  • 0 permissions asked
  • 0 accounts to create

What sets it apart

  • Fully offline — no connection needed, including when you have run out of both credit and data (precisely the moment you go looking for a code).
  • No access to your data — the app asks for neither your contacts, nor your location, nor permission to place calls on your behalf. Your country and carrier are simply read from the SIM card, with no GPS.
  • Destructive codes locked — among the codes shipped with the app, those that can wipe your phone stay visible but will not dial, with an explanation of what they do.
  • Dual SIM — two carriers selectable at once.
  • Local emergency numbers — police, gendarmerie, fire brigade, ambulance, for every country covered.

Helping out: report a code or an emergency number

Carrier codes change, and no online source is reliable everywhere. Every code in the app is either confirmed on a real handset or marked "unverified" until it is. That is where you can help — two minutes are enough:

A code works: confirm it A code does not work Suggest a missing code An emergency number is wrong or missing

The forms are in French; your browser will translate them. A report opened on GitHub is public: do not put your phone number or anything personal in it — the country, the carrier (or service) and the code (or number) are enough.

No GitHub account? Just write to levraidev@gmail.com, saying which country, which carrier or service, which code or number, and what you found.

"Unverified" does not mean "broken"

A code carries that mention for one reason only: nobody has been able to dial it on the spot yet, in that country, on a SIM of that carrier. It comes from a public source — the carrier's own pages, documentation, cross-checked listings — and it may work perfectly well. The mention says what we know, not what the code is worth.

There is only one way for it to go: someone on the spot dials the code and tells us what came back. Dialling costs nothing, and codes that take money stop at the first screen, which is enough to confirm that the right service opens.

  • It works — the code's page carries a "This code works" button; it opens a prefilled e-mail or the form above.
  • It does not work — the "Report this code" button, which asks what happened first. Retry later before reporting: a code can fail because the network is momentarily down, and the phone's error message cannot tell the difference.

The mention is lifted on two independent confirmations, or on one confirmation backed by an official carrier source. One person, once, is not enough — in either direction.

Taking part in the closed test? This is the most useful thing you can do: in your country, open the codes marked "unverified" and settle them one by one. Those are the ones nobody knows the state of yet.
